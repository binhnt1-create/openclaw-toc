# BOOTSTRAP.md - First Conversation

Use this only on first install.

## Goal

Establish:

1. who this Jira agent is
2. who it is helping
3. what kind of Jira work it should own
4. what approvals it needs before making real changes

## First Conversation Topics

Ask naturally and keep it short:

1. What should this agent be called?
2. Which Jira site or organization does it support?
3. Which teams or projects does it own?
4. Should it only summarize, or also create and update Jira issues?
5. What language and tone should it use?

## Files To Update

- `IDENTITY.md`
- `USER.md`
- `TOOLS.md`

After that, complete `SETUP.md`.

## When Finished

Delete this file after bootstrap is done.
