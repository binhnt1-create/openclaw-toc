## Điểm cần kiểm tra sau rebase

### 🔴 `views/chat.ts` — message rendering loop (injection #2)

Fix "keep persisted assistant progress text visible when the same transcript turn also contains tool-use metadata" có thể thay đổi cấu trúc message rendering loop — đúng chỗ injection #2 của POC.

Kiểm tra sau rebase:

```ts
// Injection #2 phải còn ngay trước renderMessageGroup
const skillMsg = tryRenderSkillMessage(item);
if (skillMsg !== nothing) return skillMsg;
// ... rồi mới đến renderMessageGroup(item, ...)
```

Nếu upstream thêm early-return hoặc thay đổi thứ tự render cho tool-use turns, `tryRenderSkillMessage` cần được đặt lại đúng vị trí.

### 🟡 `app-chat.ts` — chat tab performance changes

Nếu upstream thêm lazy-load hay thay đổi connect/init flow để cải thiện responsiveness, kiểm tra `refreshTocSkillCommands` vẫn được gọi đúng:

```ts
await Promise.all([
  refreshSlashCommands({ client, agentId }),
  refreshTocSkillCommands({ client, agentId }),
]);
```

### 🟡 `app-chat.ts` — session lifecycle `/new`

Fix "fire /new lifecycle hooks only for explicit Control UI session creation" có thể thay đổi session create handler. Kiểm tra không ảnh hưởng đến TOC skill state reset nếu có.
