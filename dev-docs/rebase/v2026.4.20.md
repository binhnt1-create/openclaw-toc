# Rebase Analysis — v2026.4.20

- Ngày release: 2026-04-21
- Release URL: https://github.com/openclaw/openclaw/releases/tag/v2026.4.20

## Summary upstream changes

Version lớn, chủ yếu backend/gateway/channels. Các nhóm chính:

- **Sessions/Maintenance**: session cap, age prune, cost snapshot fixes
- **Cron**: split `jobs-state.json`, isolated delivery, delivery-mode fixes
- **Plugins/startup**: bundled runtime dep repair, plugin loader alias reuse
- **Gateway**: pairing/auth/scope fixes, websocket broadcast scoping, SSRF guards
- **Agents**: compaction notices, bootstrap truncation, subagent failure payloads
- **Control UI**: cron delivery sentinel fix, device pairing scope/role display
- **Channels**: Telegram, Discord, Slack, BlueBubbles, Matrix — nhiều fix nhỏ
- **Models**: tiered pricing, Kimi K2.6 defaults, thinking normalization

## Điểm cần kiểm tra sau rebase

### 🟡 `app-chat.ts` — cron connect thêm

Nếu upstream thêm cron reconnect logic trong connect handler (gần chỗ `refreshSlashCommands`),
kiểm tra `refreshTocSkillCommands` vẫn còn được gọi song song:

```ts
// Phải còn song song với refreshSlashCommands
await Promise.all([
  refreshSlashCommands({ client, agentId }),
  refreshTocSkillCommands({ client, agentId }),
  // ... upstream có thể thêm refreshCronJobs hay tương tự
]);
```

### 🟡 `app-chat.ts` — session prune at load

Session maintenance changes có thể thêm logic vào connect/init path.
Kiểm tra không có conflict tại vị trí gọi `refreshTocSkillCommands`.

### Không cần lo về `views/chat.ts`

Release này **không thay đổi chat input UI** (toolbar, message rendering, input bar).
Tất cả 9 injection points của POC nên còn nguyên.
