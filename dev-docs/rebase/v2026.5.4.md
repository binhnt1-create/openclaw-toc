# Rebase Analysis — v2026.5.4

- Ngày release: 2026-05-05
- Release URL: https://github.com/openclaw/openclaw/releases/tag/v2026.5.4

## Summary upstream changes

Version lớn với nhiều thay đổi. Các nhóm chính:

- **Control UI/chat**: Responsive layout (phone/tablet/desktop), duplicate message collapsing, session picker cải tiến
- **Plugin skills**: Thay đổi cách publish skill qua generated directory (`~/.openclaw/plugin-skills/`)
- **Talk/STT**: Error handling cải tiến, dismissable errors
- **Gateway/performance**: Defer sidecars, fast-path startup
- **Security**: Nhiều fix SSRF, Windows path injection
- **Telegram, Discord, Slack**: Streaming và delivery fixes

## Điểm cần kiểm tra sau rebase

### 🔴 Message rendering loop

Upstream thêm duplicate-collapsing logic trong `item.kind === "group"` block — đúng chỗ injection #2.
Sau rebase, kiểm tra đoạn này còn đủ và đúng thứ tự:

```ts
if (item.kind === "group") {
  if (deleted.has(item.key)) return nothing;

  // ← injection #2 phải còn ở đây, trước mọi logic upstream mới
  const skillMsg = tryRenderSkillMessage(item);
  if (skillMsg !== nothing) return skillMsg;

  // upstream duplicate-collapsing logic sẽ nằm ở đây hoặc bên trong renderMessageGroup
  return renderMessageGroup(item, { ... });
}
```

### 🔴 Toolbar-left div

Upstream responsive restructure có thể đổi class hoặc structure của `agent-chat__toolbar-left`.
Kiểm tra injection #8 còn là button đầu tiên:

```ts
<div class="agent-chat__toolbar-left">
  ${renderFuncButton(requestUpdate, props)}  // ← phải còn đây
  <button ...>  // attach file — button tiếp theo của upstream
```

### 🟡 Plugin skills API

Upstream thêm `~/.openclaw/plugin-skills/` directory. Kiểm tra xem gateway `commands.list` response
có thay đổi field `source` hoặc structure không. Mở file `toc-slash-commands.ts` và test thử:

```ts
// Vẫn cần: entry.source === "skill" còn đúng sau v2026.5.4 không?
const skillEntries = result.commands.filter((e) => e.source === "skill");
```
